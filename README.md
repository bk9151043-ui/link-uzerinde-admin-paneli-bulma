# Link Üzerinde Admin Paneli Bulma Aracı

Hedef web sitelerinin URL'leri üzerinde tarama yaparak yaygın admin paneli yollarını tespit etmeye yarayan Python tabanlı bir araçtır.

---

## 💻 1. Kali Linux Üzerinde Çalıştırma

Bilgisayarınızda veya Kali Linux ortamında çalıştırmak için terminale sırasıyla şu komutları yazın:

```bash
git clone https://github.com/bk9151043-ui/link-uzerinde-admin-paneli-bulma.git
cd link-uzerinde-admin-paneli-bulma
python admin.py
